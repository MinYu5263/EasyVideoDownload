# 必备工具设置交互

目标：通过自定义 Rust 命令手动检测并保存 yt-dlp、FFmpeg/FFprobe 和 Deno。

约束：启动时不自动执行检测；不安装、更新或下载程序；不执行 Git 写操作；仅保存检测成功的配置；新候选失败保留上一配置。根据后续界面反馈，切换来源、选择程序和确认手动输入后自动读取信息，保留刷新按钮。

架构：Vue 管理草稿和页面状态，调用三个 Rust 命令读取配置、选择本地路径、检测并应用。Rust 统一查找路径、运行固定版本参数、检查输出并保存配置。选择器使用 Rust dialog 插件；工具配置在应用配置目录内以 JSON 原子替换保存，避免保存失败破坏上一配置。

1. 为版本识别、FFmpeg 双程序、检测失败和保存失败回退、配置恢复、进程超时和输出上限写测试并确认失败。
2. 实现 Rust 检测与持久化：固定参数、绝对路径、每个进程 10 秒上限、每路输出 64 KiB 上限、Windows 隐藏控制台。
3. 接入 Vue：手动检测、原生选择器、每卡忙碌状态、独立检测全部、真实版本/路径、错误提示、恢复配置提示、中英文。
4. 运行 Rust 测试与静态检查、前端构建；在 Windows 原生窗口验证真实工具检测、失败保留和取消选择，再做独立代码审查。

接口：RequiredToolId = ytdlp / ffmpeg / deno，source = path / manual。响应包含 active 配置和结构化 error；active 只在检测与保存均成功后更新。启动只读配置。卡片标题旁显示已安装状态，右侧显示来源和刷新，下方仅显示版本与路径。配置文件为 required-tools.json，并兼容读取旧 program-dependencies.json 和 tools.json。

审查重点：进程取消与清理、版本冒充、PATH 与含空格路径、并发保存不丢失、取消对话框不改草稿、损坏配置不被静默覆盖、所有异步分支解除忙碌状态。
